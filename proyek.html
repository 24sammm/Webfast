W-Dose

IoT & Otomasi

Alat dosing pH otomatis yang terintegrasi dengan website untuk pemantauan dan kontrol jarak jauh. Sensor pH membaca kondisi larutan secara berkala, ESP32 mengirimkannya ke server, dan pengguna dapat memantau nilai pH serta memicu pompa dosing langsung dari dasbor web.

  • C++
  • Python
  • Flask
  • HTML
  • CSS
  • JavaScript
  • ESP32
  • Sensor pH E-201C
  • PlatformIO
  • Arduino IDE
klimatologi.bmkg.internal
Dasbor Klimatologi

Sistem Informasi Klimatologi

Dasbor Data

Dasbor web untuk memvisualisasikan data parameter klimatologi BMKG pada periode mana pun. Data yang diunggah lewat berkas langsung tersaji di dasbor, lengkap dengan analisis terperinci untuk setiap parameter, grafik tren, dan visualisasi pendukung lainnya. Dibangun khusus untuk kebutuhan internal BMKG, tidak dipublikasikan untuk umum.

  • HTML
  • CSS
  • JavaScript
  • Python
